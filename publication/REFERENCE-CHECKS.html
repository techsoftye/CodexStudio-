Local paths and publishing state

The uploaded RFC folder contained old local image links in historical source exhibits. They were resolved to the six actual supplied PNG files. The selected article's original local filenames were replaced with repository-relative paths; the forum copy uses raw GitHub paths to the same images.

The repository techsoftye/CodexStudio- was read through the connected GitHub tool and was public, empty (size 0), and configured with default branch main at the time of preparation. No write, push, repository-setting change, or deployment was performed.

Links to new repository files become reachable after a successful push. The expected GitHub Pages URL becomes reachable only after Pages is enabled and deployment succeeds. Future reachability is not claimed as an already completed deployment.
