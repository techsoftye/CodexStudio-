للقراءة المنسقة على جهازك، افتح `index.html` للإنجليزية أو `ar.html` للعربية. جميع الصور والتنسيق داخل المجلد.

المقال هو **النسخة الموسعة المختارة**، وليس النسخة المختصرة ولا الصياغة الأخرى الموجودة في أرشيف المراجعة. بقي ترتيب الأقسام والصور كما هو. أُصلحت الهوية وبعض العبارات والروابط فقط.

وجد الأرشيف المرفوع بالفعل وثيقة RFC تفصيلية v1.1 في اللغتين، فضممناها **كمسودة للمراجعة**. لا نصفها بأنها وثيقة لم تُكتب، ولا نعني بإتاحتها أن المقترح منفذ أو مُعتمد.

رابط الموقع المتوقع بعد الرفع وتفعيل GitHub Pages: https://techsoftye.github.io/CodexStudio-/

**لم تُرفع الملفات أو تُفعّل Pages ضمن تجهيز الحزمة.** لا تنشر الرابط قبل التحقق من تشغيله. روابط Markdown في المستودع تعمل بعد نجاح `git push`، أما صفحة HTML فتحتاج إعداد Pages.

لا ترفع ملف ZIP نفسه باعتباره الموقع. فكّه ثم ارفع الملفات الموجودة في مجلد `CodexStudio-`، مع ملفات النقطة مثل `.nojekyll` و`.gitignore`.
